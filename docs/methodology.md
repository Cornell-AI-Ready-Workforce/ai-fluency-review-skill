# Methodology

## What is evaluated

| Area | Observable behavior |
|---|---|
| Description | Gives the AI a clear goal, context, limits, and audience. |
| Delegation | Chooses what the AI should do, what the human retains, and who checks the result. |
| Discernment | Questions output and identifies weak, missing, or unsupported claims. |
| Diligence | Checks sources, protects information, tests results, and finishes carefully. |
| Adaptive Flexibility | Uses feedback, changes the approach, verifies the change, and carries the lesson forward. |

Each area uses one whole-number label: Needs work, Developing, Moderate, Strong, or Very strong. Use Not enough evidence when the records cannot support a defensible result.

## Evidence hierarchy

Stronger evidence is attributable, repeated, and connected to a meaningful decision. Examples include a human revision with tracked changes, rejection of unsupported output, an explicit approval after verification, or a reusable rule applied in later work.

An isolated open or click only establishes interaction. A sequence such as open, inspect, revise, decide, and reuse supports a stronger inference.

## Confidence

Confidence describes evidence quality, not skill level.

- High: repeated across contexts, mostly high-confidence human attribution, with counterevidence checked.
- Medium: useful evidence exists, but attribution, context count, or comparison coverage is incomplete.
- Low: sparse, uneven, mostly agent-only, or materially ambiguous.

## Time comparison

The default comparison is recent 7 days versus the prior 14 days when both windows contain enough relevant evidence. Unequal window lengths must not be presented as a rate of change. If either period is too sparse, show the available result and mark the trend unavailable.
